# FixMyBlock
FixMyBlock is a community-driven web application design to empower neighbourhoods to report local infrastructure issues

## key features
**dynamic issue mapping:**intergrated with the **leaflet.js** map API engine to visually render neighbourhood issue notification usimg geometrical coordinate data.
**asynchronous data handling:**fetches live community report logs from the local structured server(`report.json) using the js fecth API pipeline.
**Smart validation forms:**featured isolated conditional logic tracking only when the user customized criteria is triggered.
**Responsiveness:**Standard HTML5 and CSS is visible

**latitude/longitude**: this shows the coordinates of the area in which reports are made in the map using the OpenStreetMap.
